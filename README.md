## ✨ Architectural Highlights

### 1. 🎙️ Interactive AI Voice Guide Agent (`VoiceAgent.tsx`)
- Native browser speech synthesis (`SpeechSynthesisUtterance`) with automatic voice matching (Google US English / neural voices).
- Specular audio equalizer bars pulsing dynamically across cyan & violet frequencies in sync with speech playback.
- Live word-boundary tracking closed-captions (`CC`) and subtitle progress bar for accessibility.
- Rate toggle (`1.0x`, `1.25x`, `1.5x`), replay controls, pause/resume, and minimizing orb mode.
- One-click **"AI Voice Intro"** CTA directly in the Hero Section.

### 2. 🪐 Procedural 3D WebGL Canvas (`Hero3DScene.tsx`)
- High-performance Three.js mesh with animated undulating vertex waves.
- 100-particle cyber dust constellation drifting in 3D depth with additive blending.
- Rotating orbital wireframe Torus tilted at `π/3`.
- Interactive camera and mesh parallax reacting smoothly to mouse coordinates.
- Zero-hydration SSR-safe dynamic loading with strict `prefers-reduced-motion` compliance.

### 3. 🎴 Specular 3D Tilt Cards (`Tilt3DCard.tsx`)
- Physics-based mouse tracking (`rotateX`, `rotateY`, `scale3d(1.02)`).
- Radial specular holographic glare following cursor coordinates.
- Multi-layer `preserve-3d` child popping (`translate-z-10`, `translate-z-20`, `translate-z-30`).
- Seamlessly wrapped around project cards, certificates, achievements, and gallery moments.

### 4. 🏆 Verified Credentials Lightbox (`CertificatesGallery.tsx`)
- 25 verified records across hackathon championships (AIdeastorm 1st Prize, Luminix Runner-Up, HackHazards Top 100), industry certifications (Salesforce, Deloitte, Infosys, Guvi), and internship appointments (DevStack, Aethriz AI, Swiftly Seva, SkillCraft, InAmigos).
- Instant interactive modal preview with high-res lightbox and full PDF document rendering.

### 5. 📸 Authentic Builder Journey (`PersonalGallerySection.tsx`)
- 14 real photographic moments documenting Bishnu's journey from competitive amphitheaters to podium envelope presentations and live Cambridge Institute of Technology demonstrations.

## 🚀 Local Development Setup

### 1. Prerequisites
- **Node.js**: `v18.17+` or `v20+` (Tested on Node `v24`)
- **Package Manager**: `npm`, `pnpm`, or `yarn`

### 2. Clone the Repository
```bash
git clone https://github.com/bishnu24ise-prog/personal-portfolio.git
cd personal-portfolio
```

### 3. Install Dependencies
```bash
npm install
```

### 4. Run Locally
```bash
npm run dev
```
Navigate to **[http://localhost:3000](http://localhost:3000)** in your browser.

### 5. Build for Production
```bash
npm run build
npm run start
```

## ✏️ How to Customize & Add Content

All portfolio content is centralized in **one single typed file**:  
👉 **[`src/data/portfolio.ts`](src/data/portfolio.ts)**

- **To Add a New Project**: Append an object to `FEATURED_PROJECTS` or `MORE_PROJECTS`.
- **To Add a Certificate / Award**: Place image in `public/certificates/` and append to `CERTIFICATES_GALLERY`.
- **To Add a Builder Moment**: Place image in `public/gallery/` and append to `PERSONAL_GALLERY`.
- **To Add Work Experience**: Append an object to `EXPERIENCES`.
- **To Update Skills / LeetCode / Links**: Edit `PERSONAL_INFO` or `SKILL_GROUPS`.
